# GitHub Models (Free for Prototypes)

GitHub offers free access to top AI models like GPT-4o and Llama 3 for GitHub users to experiment and build within the GitHub ecosystem.

## 🚀 Key Specs (2026 Update)
- **Model Support**: GPT-5.1, GPT-5.2 mini, GPT-5.2 nano, Llama 3.3.
- **Access Policy**: Prototyping and internal evaluation only (commercial use prohibited).
- **Daily Caps (Free)**:
  - **High Tier (GPT-5, o2)**: 10 RPM, 50 RPD.
  - **Low Tier (Llama 8B, mini)**: 15 RPM, 150 RPD.
- **Integration**: Native support in GitHub Codespaces and VS Code.


## 🗝 How to get started
1. Visit [GitHub Models](https://github.com/marketplace/models).
2. Choose a model.
3. Use the integrated playground or follow the "How to Use" SDK instructions (Python/JS).
